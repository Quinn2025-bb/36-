# 36 周主题挑战

一个可爱猫咪风格的「一年 36 周主题挑战」抽签网页。把一年拆成 9 个月 × 4 周 = 36 周，每周通过抽签确定一个低成本的体验主题去完成，并记录每一次体验。

- 纯前端单文件（`index.html`），双击即可打开，无需任何服务器
- 数据存在各自浏览器的本地存储里，**每个人看到的是自己的记录**
- 移动端优先，桌面端有侧边栏导航

## 二、如何部署上线（让别人也能访问）

推荐部署到 **GitHub Pages**，完全免费、永久有效、全球可访问。下面是两种方式，选一种即可。

### 方式一：网页上传（最简单，推荐新手，约 5 分钟）

1. 打开 [github.com](https://github.com)，登录（没有账号就点 Sign up 免费注册一个）。
2. 点右上角 **＋** → **New repository（新建仓库）**。
3. 仓库名填 `themed-week`，可见性选 **Public（公开）**，然后点 **Create repository**。
   > 注意：GitHub Pages 只对「公开仓库」免费。
4. 进入刚创建的仓库页面，点 **Add file** → **Upload files（上传文件）**。
5. 把 `index.html` 拖进上传区域，点下方绿色的 **Commit changes（提交）**。
6. 点仓库顶部 **Settings（设置）** → 左侧 **Pages**。
7. 在 **Source** 里选 **Deploy from a branch**，Branch 选 **main**，目录选 **/ (root)**，点 **Save（保存）**。
8. 等待 1～2 分钟，页面会提示：
   > Your site is live at `https://你的用户名.github.io/themed-week/`
9. 把这个链接发给朋友，对方打开即可使用。

### 方式二：git 命令行（适合熟悉 git 的用户）

```bash
# 1. 进入项目目录
cd /Users/wangwenqing/CodeBuddy/202610_ThemedWeek

# 2. 初始化并提交
git init
git add index.html README.md
git commit -m "36 周主题挑战"

# 3. 关联远程仓库（把下面的"你的用户名"换成你自己的）
git remote add origin https://github.com/你的用户名/themed-week.git
git branch -M main
git push -u origin main
```

推送完成后，到 GitHub 仓库的 **Settings → Pages**，把 Source 设为 **main / root** 并保存，等待 1～2 分钟即可拿到访问链接。

## 三、使用指南

打开网页后，会看到 4 个功能区（桌面端在左侧导航栏，手机端在底部 Tab 栏）：

### 1. 抽签
- 点 **「抽本周主题」** 按钮
- 弹出「大类勾选」面板，默认勾选大部分分类（**厨房美食**默认不勾选，等你具备条件再手动勾上）
- 点 **「开始抽签」** → 小猫摇晃 + 光点动画 + 音效 → 弹出结果
- **「就选它」**：锁定本周主题（锁定后不可改）
- **「再抽一次」**：不满意就重抽，每周最多 3 次机会（首抽 + 2 次重抽）

### 2. 主题墙
- 按「第 1 月 ～ 第 9 月」展示 36 个周槽位
- 每个月的卡片里还内嵌了 **月度体验计划** 和 **情侣共同计划**，点击可填写

### 3. 主题库
- 7 大类主题（学习成长 / 生活日常 / 厨房美食 / 手工创作 / 艺术表达 / 运动健康 / 户外探索）
- 点分类可只看某一类；主题标签上的 ✕ 可删除
- 底部输入框 + 分类下拉可**新增自己的主题**

### 4. 完成记录
- 已完成的周会在这里倒序展示
- 点进去可标记「完成 / 未完成」、填写或修改体验记录

## 五、数据说明（重要）

- 所有记录（抽签结果、完成状态、体验笔记、计划）都存在**你自己浏览器的本地存储（localStorage）**里。
- **每个人各用各的**：你抽的主题、写的记录，别人看不到；别人打开也有自己独立的一份。
- **换设备 / 换浏览器 / 清除浏览器缓存，记录会丢失**——这是「各自独立」设计的代价。
- 如果你希望未来能「多设备同步」或「和伴侣共享同一份进度」，需要额外接云数据库，可再单独沟通。

## 六、常见问题

**Q：我想重新开始，怎么清空所有进度？**
A：在浏览器里打开网页，按 F12 打开控制台，输入并回车：
```js
window.__resetThemedWeek()
```
会弹出二次确认，确认后所有数据重置。

**Q：抽签时提示「没有可用主题」怎么办？**
A：说明你勾选的大类里，主题都已经被抽完了。去「主题库」新增主题，或在抽签时勾选更多大类。

**Q：手机和电脑上的记录不一样？**
A：正常现象。记录存在各自的浏览器里，手机和电脑是两份独立数据。

**Q：为什么别人打开看不到我的记录？**
A：因为记录是「各自独立」的，存在每个人自己的浏览器里，不会共享。这是当前设计。
